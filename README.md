
# MAGISTO TECHY — Creator Portfolio

A personal portfolio website for Abhinand A.S., featuring technology content creation, UGC services, brand collaborations and featured projects.

## Website Structure

```text
Portfolio-M/
│
├── index.html
├── README.md
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
└── assets/
    └── portrait.png
```

## Setup

1. Download or clone this repository.
2. Keep the HTML, CSS and JavaScript files in their respective folders.
3. Add your portrait image to the `assets` folder.
4. Rename the image to `portrait.png`.
5. Open `index.html` in a browser.

## Deployment

This website uses plain HTML, CSS and JavaScript.

It can be hosted using GitHub Pages without installing Node.js or running a build command.

For GitHub Pages:

1. Open repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/(root)`.
5. Save and wait for deployment.

Your website URL should be:

https://magistocoder.github.io/Portfolio-M/
